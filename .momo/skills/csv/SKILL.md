# CSV Profiler Skill

This skill provides automated tools to analyze CSV files used in the design framework. It ensures data integrity before ML training and simulation sweeps.

## Capabilities
- Header extraction and column indexing.
- Numerical range analysis (Min, Max, Mean).
- Null value detection and empty row counting.
- Dataset size profiling.
- Data filtering for failed or anomalous runs.
- Statistical anomaly detection using standard deviation ($\sigma$) and absolute physical bounds.

## Scripts
- `analyze_csv.py`: Performs a comprehensive profile of the target CSV.
- `filter_csv.py`: Extracts rows based on status or null values.
- `anomaly_detector.py`: Detects values outside specified bounds or those exceeding statistical thresholds (e.g., $3\sigma$).

# Tool Usages Guide

## Report Generation Standard
To ensure deterministic and verifiable reports, Momo must follow these rules:
1. **Zero Memory Reporting**: Never report statistics or findings from memory or previous LLM turns.
2. **Script-Driven Documentation**: All reports must be generated by an executable Python script.
3. **The Pipeline**: `Data (CSV)` $\rightarrow$ `Analysis Script (Python)` $\rightarrow$ `Report (Markdown)`.
4. **Deterministic Logic**: Scripts must use fixed seeds for any sampling and explicit formatting for tables to ensure the report is reproducible.
5. **Verification**: Every report must be accompanied by the script that generated it, stored in `scripts/`.


## Usage
Run the scripts from the project root using:
`python .momo/skills/csv/scripts/analyze_csv.py --file <path_to_csv>`
`python .momo/skills/csv/scripts/filter_csv.py --file <path_to_csv> [--out <output_csv>]`
`python .momo/skills/csv/scripts/anomaly_detector.py --file <path_to_csv> --column <col_name> --min <val> --max <val>`
